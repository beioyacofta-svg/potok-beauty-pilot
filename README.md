# Поток — GitHub Pages

Статический мобильный прототип записи для самостоятельных бьюти-мастеров.

## Публикация на GitHub Pages

1. Создайте в аккаунте `beioyacofta-svg` публичный репозиторий `potok-beauty-pilot` без README, лицензии и `.gitignore`.
2. Загрузите в его корень файлы из этой папки: `index.html`, `.nojekyll` и этот README.
3. Откройте **Settings → Pages**. В блоке **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем нажмите **Save**.
4. Через 1–3 минуты приложение будет доступно по адресу: `https://beioyacofta-svg.github.io/potok-beauty-pilot/`.

Приложение хранит данные только в браузере устройства (`localStorage`): записи, клиенты и услуги не передаются на сервер и не синхронизируются между телефонами.
